# Features Roadmap

Proposed features we can add to the Budget Tracker. Check off items as they ship.

> Legend: each unchecked box is a feature we do not have yet. See `optimization.md` for improvements to existing features. Recent shipped notes and guides live in [docs/](docs/README.md). For the flat build-next checklist, see [features2.md](features2.md).
